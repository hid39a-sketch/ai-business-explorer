# 崩れ三尊 EA（MT5・売り専用）

FX-Clover のポコさん（[@clover_fx](https://x.com/clover_fx)）が「最も気に入っている取引パターン」として紹介している**崩れ三尊①②③の右肩**だけを狙う MT5 用 EA です。

- ファイル: `KuzureSanzonEA.mq5`
- 対応: MetaTrader 5
- 売りのみ（買いのロジックはありません）
- 執行足はパラメーターで変更できます（初期値は15分足）

> この EA は利益を保証しません。ストラテジーテスターとデモ口座で十分に検証してから使ってください。

## 2. ルールと EA の対応

| 作者のルール | EA での判定 | 主なパラメーター |
|---|---|---|
| 上位足のスラスト（トップから50〜60pips の下落） | 上位足の直近 N 本の高値から、安値まで `InpThrustPips` 以上下げている | `InpUpperTF` `InpThrustPips` `InpThrustLookback` |
| ワクワクさん（任意） | 上位足で、陰線の実体が DMA3x3 を上から下に割った足がある | `InpRequireWakuwaku` |
| 崩れ三尊①②③（右肩下がり） | 執行足の直近の山3つで、②≦①（誤差まで可）、③＜② | `InpPivotBars` `InpPatternBars` `InpEqualTolPips` `InpMinStepPips` |
| ①はスラストのあと | ①の時刻が、上位足の高値の足より後 | — |
| ③を 25-5MA に引っ掛けて落とす（グランビル） | ③の高値が DMA25x5 に届いている。かつ DMA25x5 が下向き | `InpMaTouchPips` `InpSlopeBars` `InpMinSlopePips` |
| 5文字相場は見送る | DMA25x5 の傾きが小さければ入らない | `InpMinSlopePips` |
| 安値を抜いて 3-3 割れでエントリー | 確定足が陰線で、DMA3x3 と DMA25x5 の下で終わり、①〜③の間の安値（ネック）を初めて終値で割った | `InpRequireNeckBreak` `InpMaxBarsAfterR` |
| 損切りは右肩の上 | ③の高値＋`InpSLBufferPips`＋スプレッド | `InpSLBufferPips` `InpMaxSLPips` |
| 利確 SL:TP＝1:1、または FE | RR（初期値1.0）か、③から（①−ネック）×比率 | `InpTPMode` `InpRR` `InpFERatio` |
| 3-3上で確定したら切る（任意） | 確定足が DMA3x3 の上で終わったら決済 | `InpExitOnFastAbove` |

### EA では再現していないもの

次の要素は裁量の部分が大きいため、まだ入れていません。検証しながら追加を検討してください。

- 上位足のゾーン（サポートとレジスタンスの入れ替わり）、砦、手で引くトレンドライン
- フィボナッチ・リトレースメント38.2%との重なり
- 「左肩と同じくらいの時間をかけて右肩ができる」というバランス
- 安値更新タイプ（ネックのリトレースを右肩とみなす型）

## 3. 使い方

1. MT5 で **ファイル → データフォルダを開く** を選びます。
2. `MQL5/Experts/` に `KuzureSanzonEA.mq5` をコピーします。
3. MetaEditor でファイルを開き、**コンパイル**（F7）します。エラーが出たら、その内容を教えてください。
4. MT5 の **表示 → ストラテジーテスター** で次のように設定します。
   - エキスパート: `KuzureSanzonEA`
   - 銘柄: GBPJPY など（作者は GBPJPY、EURJPY、EURAUD、USDCAD などで使っています）
   - 時間足: 執行足と同じ（初期値は M15）
   - モデル: 「リアルティックに基づいた全ティック」を推奨
   - ビジュアルモードにすると、エントリーした①②③（赤い数字）とネック（青い線）がチャートに描かれます
5. 結果を見て、パラメーターを調整します。

### 執行足を変える場合の目安

| 執行足 | `InpUpperTF` | `InpThrustPips` | `InpMaxSLPips` |
|---|---|---|---|
| M1 | M15〜H1 | 20〜50 | 15 |
| M5 | H1 | 50 | 25 |
| M15（初期値） | H1 | 50 | 40 |

数値は目安です。通貨ペアによって値動きの大きさが違うので、検証して決めてください。

## 4. 今後の追加候補

- 執行足を複数（例: M1・M5・M15）同時に監視する
- 上位足の MA の向き（75・200・600）のフィルター
- FR38.2% との重なりのフィルター
- 安値更新タイプの崩れ三尊
- 分割決済（T①・T②）
